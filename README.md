# İzhar Medya — Portfolio

A responsive portfolio site for İzhar Medya, presenting video editing, motion design, and selected creative work.

**Live site:** [izharmedya.store](https://izharmedya.store)

## Preview locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static web server.

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Built with

- Semantic HTML
- Custom CSS and responsive layouts
- Vanilla JavaScript

The `assets/` folder contains the portfolio's visual assets and demo videos. Their ownership or third-party terms are separate from the source-code license.
