# Instagram Reel kapakları

Bu klasörde portföydeki Instagram Reels için dikey kapak görselleri bulunur.
Dosya adı, Reel kısa koduyla eşleşir; örneğin `DekDrhcR4xM.jpg` dosyası
`instagram.com/reel/DekDrhcR4xM/` bağlantısına aittir.

Yeni bir Reel eklerken kapağı bu klasöre aynı adlandırma kuralıyla koyun ve
`index.html` içindeki Instagram Reels şeridine resmi Reel embed bağlantısıyla
bir kart ekleyin.
